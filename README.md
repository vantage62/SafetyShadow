# Safety Shadow — A Privacy-First Silent Guardian

> Not just an alarm. A guardian that notices.

## About

**Safety Shadow** is a ₹1,500 wrist band designed to protect school children, women on public transport, and elderly people living alone.

Created by **Shadow Squad** (Class 10 students from CM SHRI Yamuna Vihar, Delhi) for the **Seva First Innovation Challenge 2026** (Junior Level, Class 6–12).

### The Core Problem
Today's safety devices only work if the victim presses SOS, and panic is exactly when hands freeze. If a phone is snatched or switched off, parents and police see "Location Unknown".

### The Solution: Learn, Detect, Confirm, Escalate
```text
      Daily Commute
           │
           ▼
    1. Learn Route (3-4 days, local pattern only)
           │
           ▼
    2. Detect Anomaly (Deviation >500m, Stop >15min, Fall >2.5g)
           │
           ▼
    3. Silent Confirmation (45s vibration check: 1 tap OK, 2 taps help)
           │
           ▼
    4. Multi-Tier Escalation (Parent App -> 2nd Contact -> Police)
           │
           ▼
    "Last Safe Point: 7:42 PM at Metro Gate 3"
```

## Hardware Specifications (₹1,500 Unit Cost)
- **ESP32-C3 SuperMini** (Brain, BLE link): ₹350
- **MPU6050 Motion Sensor** (Fall & impact detection): ₹150
- **Coin Vibration Motor + Tactile Switch**: ₹150
- **500 mAh LiPo (402030) + TP4056 Type-C Charger**: ₹250
- **Custom PCB (35 × 28 mm) + Case (40 × 40 × 12 mm)**: ₹200
- **Reinforced Band**: ₹400
- **Battery Life**: ~20 hours (covers 2 full school days)
